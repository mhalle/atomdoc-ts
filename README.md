# atomdoc-ts has moved

This repository is archived. The TypeScript client now lives in the
`typescript/` directory of the AtomDoc monorepo, alongside the Python
package and the protocol specification:

https://github.com/mhalle/atomdoc

The full history of this repository is preserved there; its releases are
tagged `ts-v0.4.0` through `ts-v0.4.2`. Later releases tag the monorepo
once (`vX.Y.Z`) for both packages.
